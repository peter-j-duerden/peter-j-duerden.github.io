# Humungous Techie

The website for Fretwork and the other Humungous Techie apps: https://peter-j-duerden.github.io

Plain HTML and one stylesheet, served by GitHub Pages. No scripts, cookies or tracking.

- `index.html`: home page
- `fretwork/`: about Fretwork
- `support/`: help, and where to report problems (this repo's Issues)
- `privacy/`: the privacy policy, linked from the Microsoft Store listing
